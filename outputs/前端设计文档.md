# 前端设计文档

## 1. 设计理念

### 1.1 核心价值

本项目是一个智能文档处理系统，旨在为用户提供高效、直观的文档交互体验。设计理念围绕以下核心价值展开：

- **简洁高效**：减少认知负担，让用户专注于文档内容和交互本身
- **智能直观**：通过智能设计引导用户完成任务，减少学习成本
- **专业可信**：传达技术实力和可靠性，建立用户信任
- **现代美感**：采用现代设计语言，提供愉悦的视觉体验

### 1.2 目标用户

- **学生**：需要快速理解学习材料，准备考试
- **研究人员**：需要分析大量学术论文和研究资料
- **职场人士**：需要处理合同、报告、手册等专业文档
- **教育工作者**：需要整理和分析教学材料

## 2. 设计风格

### 2.1 整体风格

采用**现代简约**风格，结合**科技感**和**专业性**，创造一个既美观又实用的界面。

- **主色调**：深蓝色 (#1a365d) - 传达专业、可信和科技感
- **辅助色**：浅蓝色 (#4299e1) - 用于强调和交互元素
- **中性色**：深灰 (#2d3748)、中灰 (#718096)、浅灰 (#e2e8f0)、白色 (#ffffff)
- **强调色**：橙色 (#ed8936) - 用于关键操作和通知

### 2.2 排版

- **标题字体**：Inter - 现代无衬线字体，清晰易读
- **正文字体**：Roboto - 优秀的屏幕显示字体，可读性强
- **字体大小**：
  - 大标题：24-32px
  - 中标题：18-24px
  - 正文：14-16px
  - 辅助文字：12-14px
- **行高**：正文 1.5，标题 1.2

### 2.3 视觉元素

- **图标**：使用线性图标，保持简洁一致
- **阴影**：轻微的阴影效果，增加层次感
- **圆角**：适度的圆角设计，增强现代感
- **动画**：流畅的过渡动画，提升用户体验
- **留白**：充足的留白，提高信息可读性

## 3. 页面布局

### 3.1 整体布局

采用**三栏式布局**，响应式设计：

- **左侧**：文档导航栏，显示上传的文档和文件夹
- **中间**：主内容区，显示文档内容或聊天界面
- **右侧**：辅助信息区，显示摘要、引用或相关信息

### 3.2 响应式设计

| 断点 | 宽度范围 | 布局 | 说明 |
|------|----------|------|------|
| 桌面端 | ≥1024px | 三栏布局 | 完整功能，左栏固定 |
| 平板端 | 768-1023px | 双栏布局 | 可折叠侧边栏，右侧面板浮层 |
| 移动端 | <768px | 单栏布局 | 底部导航切换功能 |

## 5. 路由结构设计

### 5.1 路由表

| 路径 | 组件 | 认证 | 说明 |
|------|------|------|------|
| `/` | `HomePage` | 否 | 首页/落地页 |
| `/login` | `LoginPage` | 否 | 登录页 |
| `/register` | `RegisterPage` | 否 | 注册页 |
| `/documents` | `DocumentsPage` | 是 | 文档管理页 |
| `/chat` | `ChatPage` | 是 | 聊天页（默认无会话） |
| `/chat/:chatId` | `ChatPage` | 是 | 聊天页（指定会话） |
| `*` | `NotFoundPage` | 否 | 404页面 |

### 5.2 路由守卫

```tsx
<BrowserRouter>
  <Routes>
    <Route element={<PublicRoute />}>
      <Route path="/" element={<HomePage />} />
      <Route path="/login" element={<LoginPage />} />
      <Route path="/register" element={<RegisterPage />} />
    </Route>
    <Route element={<ProtectedRoute />}>
      <Route element={<AppLayout />}>
        <Route path="/documents" element={<DocumentsPage />} />
        <Route path="/chat" element={<ChatPage />} />
        <Route path="/chat/:chatId" element={<ChatPage />} />
      </Route>
    </Route>
    <Route path="*" element={<NotFoundPage />} />
  </Routes>
</BrowserRouter>
```

- **PublicRoute**：已登录用户访问公开页面时重定向到`/documents`
- **ProtectedRoute**：未登录用户访问受保护页面时重定向到`/login`

```typescript
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;

```

### 7.3 响应拦截器

```typescript
apiClient.interceptors.response.use(
  (response) => {
    const { code, message, data } = response.data;
    if (code !== 0) {
      return Promise.reject({ code, message });
    }
    return data;
  },
  async (error) => {
    if (error.response?.status === 401) {
      const refreshed = await attemptRefreshToken();
      if (refreshed) {
        return apiClient(error.config);
      }
      store.dispatch(logout());
      window.location.href = '/login';
    }
    const { code, message } = error.response?.data || {};
    return Promise.reject({ code: code || 5001, message: message || '网络错误' });
  }
);
```

### 7.4 统一错误处理

| 错误码范围 | 前端处理 |
|-----------|----------|
| 1000-1999 | 认证错误 → 跳转登录页或刷新Token |
| 2000-2999 | 参数错误 → 表单提示 |
| 3000-3999 | 文档错误 → 页面内Toast提示 |
| 4000-4999 | 聊天错误 → 聊天窗口内提示 |
| 5000-5999 | 系统错误 → 全局错误页面 |

## 8. WebSocket实时通信设计

### 8.1 连接管理

```typescript
function useWebSocket() {
  const connect = () => {
    const token = store.getState().auth.accessToken;
    const ws = new WebSocket(`${WS_BASE_URL}/ws/chat?token=${token}`);

    ws.onopen = () => { /* 更新连接状态 */ };
    ws.onmessage = (event) => { /* 分发消息到Redux */ };
    ws.onclose = () => { /* 自动重连（指数退避） */ };
    ws.onerror = () => { /* 错误处理 */ };

    return ws;
  };

  const sendMessage = (data: ChatMessageData) => {
    ws.send(JSON.stringify({ type: 'chat_message', data }));
  };

  return { connect, sendMessage, disconnect };
}
```

### 8.2 消息类型映射

| WebSocket消息类型 | Redux Action | UI行为 |
|------------------|-------------|--------|
| `chat_start` | `chat/streamStart` | 显示加载状态，创建消息占位 |
| `chat_chunk` | `chat/streamChunk` | 逐步更新消息内容（打字机效果） |
| `chat_end` | `chat/streamEnd` | 显示引用来源，完成消息 |
| `error` | `chat/streamError` | 显示错误提示 |
| `ping`/`pong` | - | 心跳保活 |

### 8.3 重连策略

- 首次重连延迟：1秒
- 最大重连延迟：30秒
- 指数退避因子：2
- 最大重连次数：10次
- 重连期间UI显示"重新连接中"提示

## 11. 错误边界与加载状态

### 11.1 错误边界(Error Boundary)

```tsx
class ErrorBoundary extends React.Component<
  { fallback?: ReactNode; children: ReactNode },
  { hasError: boolean; error: Error | null }
> {
  static getDerivedStateFromError(error: Error) {
    return { hasError: true, error };
  }
  render() {
    if (this.state.hasError) {
      return this.props.fallback || <ErrorFallback error={this.state.error} />;
    }
    return this.props.children;
  }
}
```

使用策略：
- 全局ErrorBoundary包裹`<App />`
- 页面级ErrorBoundary包裹每个页面组件
- 组件级ErrorBoundary包裹复杂组件（如PDF预览器）
